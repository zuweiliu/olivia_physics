Vectors: Direction Matters!

When you say a car goes 60 km/h, that's speed — just a number. But when you say it goes 60 km/h north, that's velocity — a number plus a direction. This difference is the key to understanding vectors.

💡 Scalar vs Vector

Scalars (magnitude only)

Speed, mass, distance, time, energy, temperature

Example: "The box weighs 5 kg"

Vectors (magnitude + direction)

Velocity, force, acceleration, displacement

Example: "Push with 10 N at 30° above horizontal"

How We Draw Vectors

A vector is drawn as an arrow:

  • Length of the arrow = magnitude (how big)
  • Direction the arrow points = direction of the vector
  • The tail is where it starts; the tip is the arrowhead

⭐ Breaking a Vector into Components

This is the most important skill in this lesson. Any vector can be split into an x-component and a y-component.

\[ \vec{V} = V_x\,\hat{x} + V_y\,\hat{y} \]

If the vector makes angle \(\theta\) with the positive x-axis:

\( V_x = V \cos\theta \) \( V_y = V \sin\theta \)
Think of it this way: cos goes with the adjacent side (along x), and sin goes with the opposite side (along y). SOH-CAH-TOA!

Signs in Each Quadrant

The sign of each component depends on which quadrant the vector points into:

Quadrant II (90°–180°)
Vx < 0   Vy > 0
Quadrant I (0°–90°)
Vx > 0   Vy > 0
Quadrant III (180°–270°)
Vx < 0   Vy < 0
Quadrant IV (270°–360°)
Vx > 0   Vy < 0

Tip: Using \(\cos\theta\) and \(\sin\theta\) with the standard angle (from +x axis) automatically gives you the correct sign. No need to memorize!

🏔️ Forces on an Inclined Plane

This is where many students get confused! On a slope, we rotate our coordinate system so that x is along the slope and y is perpendicular to it.

Gravity \(mg\) always points straight down, but in the rotated coordinates:

\( F_{\parallel} = mg\sin\theta \) \( F_{\perp} = mg\cos\theta \)
⚠️ Notice the SWAP!

On a flat surface: \(F_x = F\cos\theta\), \(F_y = F\sin\theta\).
On a slope: \(F_{\parallel} = mg\sin\theta\), \(F_{\perp} = mg\cos\theta\).
This is because the angle θ of the slope is measured from the horizontal, but gravity points vertically. The angle between gravity and the perpendicular-to-slope direction equals the slope angle θ.

Adding Vectors: The Component Method

To add two vectors \(\vec{A}\) and \(\vec{B}\):

  1. Find components: \(A_x, A_y\) and \(B_x, B_y\)
  2. Add components: \(R_x = A_x + B_x\), \(R_y = A_y + B_y\)
  3. Find resultant magnitude: \(R = \sqrt{R_x^2 + R_y^2}\)
  4. Find resultant angle: \(\theta = \tan^{-1}\!\left(\frac{R_y}{R_x}\right)\)

Section 3 of 6 — Worked Example

Example: Force Components 🔧

Problem 1

A person pushes a box with a force of 50 N at an angle of 37° above the horizontal. Find the horizontal and vertical components of this force.

1
Draw the picture & identify the angle

Label the force, angle, and axes

The force \(\vec{F} = 50\) N points at \(\theta = 37°\) above the positive x-axis. Since the angle is measured from the horizontal (x-axis), we use the standard formulas directly.

2
Find \(F_x\) using cosine

Horizontal component

\[ F_x = F\cos\theta = 50 \times \cos(37°) = 50 \times 0.7986 = \boxed{39.9\ \text{N}} \]

Cos gives the adjacent (horizontal) component.

3
Find \(F_y\) using sine

Vertical component

\[ F_y = F\sin\theta = 50 \times \sin(37°) = 50 \times 0.6018 = \boxed{30.1\ \text{N}} \]

Sin gives the opposite (vertical) component.

4
Verify with Pythagorean theorem

Should get back 50 N

\[ F = \sqrt{F_x^2 + F_y^2} = \sqrt{39.9^2 + 30.1^2} = \sqrt{2498} \approx 50.0\ \text{N}\ \checkmark \]

Problem 2: Block on a Slope

A 10 kg block sits on a 30° inclined plane. Find the component of gravity along the slope and perpendicular to the slope.

1
Set up the rotated coordinate system

x along slope, y perpendicular to slope

Weight: \(mg = 10 \times 9.80 = 98\ \text{N}\) pointing straight down.
On a slope, the angle between \(\vec{mg}\) and the perpendicular-to-slope direction equals the slope angle \(\theta = 30°\).
This is why the formulas swap!

2
Calculate both components
\[ F_{\parallel} = mg\sin\theta = 98 \times \sin(30°) = 98 \times 0.5 = \boxed{49\ \text{N}} \] \[ F_{\perp} = mg\cos\theta = 98 \times \cos(30°) = 98 \times 0.866 = \boxed{84.9\ \text{N}} \]

Check: \(\sqrt{49^2 + 84.9^2} \approx 98\ \text{N}\) ✓

Homework Problems 📝

Problem 1

A rope pulls a sled with a force of 120 N at 25° above the horizontal. Find the horizontal and vertical components of the tension force.

\(T_x = 120\cos(25°) = 108.7\ \text{N}\), \(T_y = 120\sin(25°) = 50.7\ \text{N}\)
Problem 2

A 5 kg box slides down a 40° incline. Find the component of gravity along the slope and perpendicular to the slope.

\(F_{\parallel} = 49\sin(40°) = 31.5\ \text{N}\), \(F_{\perp} = 49\cos(40°) = 37.5\ \text{N}\)
Problem 3

Two forces act on an object: \(\vec{F_1} = 80\) N at 0° and \(\vec{F_2} = 60\) N at 90°. Find the magnitude and direction of the resultant force.

\(R = \sqrt{80^2+60^2} = 100\ \text{N}\), \(\theta = \tan^{-1}(60/80) = 36.9°\)
Problem 4

A velocity vector has components \(v_x = -12\) m/s and \(v_y = 16\) m/s. Find the magnitude and direction (angle from +x axis).

\(v = 20\ \text{m/s}\), \(\theta = 126.9°\) from +x axis (Quadrant II).
Problem 5

A car on a banked curve (bank angle 20°). The normal force is 12,000 N. Find the horizontal and vertical components of the normal force.

\(N_x = 12000\sin(20°) = 4104\ \text{N}\), \(N_y = 12000\cos(20°) = 11276\ \text{N}\)
